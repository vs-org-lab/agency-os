# Agency OS

Internal operating platform for the agency.

## Repository conventions

- Default branch: `main` (protected). Integration branch: `develop`.
- Work is done on `feature/*`, `fix/*` and `chore/*` branches and merged through pull requests.
- Commits follow [Conventional Commits](https://www.conventionalcommits.org/).
- Engineering guidelines: see [CLAUDE.md](CLAUDE.md).
